What is this?

A conversational knowledge base for Docker

This project is a Retrieval-Augmented Generation (RAG) application built to make Docker documentation searchable and conversational. Instead of digging through dense docs, you ask a question in plain English and get a focused, contextual answer.

The knowledge base is hosted on AWS Bedrock, which handles document ingestion, chunking, and vector retrieval. Retrieved chunks are then passed to a locally running Ollama model for generation — keeping inference costs at zero while maintaining full control over the output.

The problem

Docker docs are dense

Docker's official documentation is extensive and well-written, but finding a specific answer often means navigating multiple pages, cross-referencing CLI references, and piecing together examples from different sections.

This app collapses that search into a single query. Ask naturally, get a grounded answer.

How it works

The pipeline

Every query goes through a two-stage process. First, AWS Bedrock retrieves the most semantically relevant chunks from the knowledge base. Then those chunks are passed to Ollama running locally, which generates a coherent answer grounded in the retrieved content — not model memory alone.

Your Query → AWS Bedrock Retrieve → Relevant Chunks → Ollama (local LLM) → Generated Answer
